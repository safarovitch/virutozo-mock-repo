| D1-15 | missing detail | `guard-tests` (HOOK-3) | Same class as D1-08: the hook matches `.skip(`, `.only(`, `xit(` and `expect(` anywhere in the text, including strings and comments. | D1-16 | missing detail | `guard-bash` entry check | The hook runs its blocking code only if `import.meta.url` equals `file://` + `process.argv[1]`. The unit tests don't catch it because they import `check()` directly. | Compare real paths (`realpathSync(process.argv[1]) === fileURLToPath(import.meta.url)`), or move `check()` into its own module so the hook file has no entry check. Add one black-box test that runs the hook as a process, including through a symlink. |
